# Smailr 邮件助手

> 专为 Smailr 设计，提供了便捷的扩展功能。

> [最新V2.1版本下载地址](https://github.com/EvanTop/smailr-mail-assistant/releases)

**Smailr 邮件助手**是一个基于 **Manifest V3** 的 Chromium 浏览器扩展。它通过用户自行创建的 Smailr API 密钥，在任意浏览器页面的工具栏中快速查看收件箱、切换多个账户并接收新邮件提醒。扩展以本地存储为中心，不依赖读取网页端的登录会话；首次配置完成后即可从浏览器工具栏使用。

| 项目 | 当前信息 |
| --- | --- |
| 当前版本 | `1.1.0` |
| 扩展标准 | Manifest V3 |
| 支持浏览器 | 支持 Manifest V3 的 Chromium 浏览器，例如 Google Chrome、Microsoft Edge |
| 账户数量 | 最多 8 个 |
| 作者 | Design by [Evan](https://evan.xin) |

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 工具栏邮件查看 | 无需打开 Smailr 网页邮箱，在任意网页点击扩展图标即可查看已同步的邮箱和收件箱邮件。 |
| 多账户快速管理 | 支持添加、切换、重命名及从本机移除最多 8 个账户。每个账户的缓存、邮箱备注、待提示未读状态和本地隐藏记录相互隔离。 |
| 邮件详情与复制 | 点击邮件标题即可读取正文，并可一键复制纯文本内容。 |
| 本地隐藏邮件 | 可将邮件从扩展列表中移除，不会删除、归档或修改 Smailr 服务端邮件。 |
| 联动未读提醒 | 新邮件可触发系统通知、声音及工具栏数字角标；打开邮件或清除提醒会同步更新扩展内的小红点、未读提示和工具栏角标。 |
| 角标闪动与配色 | 有待提示的新邮件时，工具栏角标规律闪动；支持红色与绿色两种角标配色。 |
| 自动或手动同步 | 可选 1、2、5、10 或 15 分钟后台检查。关闭自动检查后，扩展只会在点击右上角刷新按钮时更新。 |
| 邮箱备注 | 可为每个邮箱地址添加本地备注，并在邮箱选择菜单中显示。 |
| 声音控制 | 可独立开关声音提醒，并在开启时播放测试音。 |

## 安装

本项目当前以源代码目录方式发布。Chrome 官方文档说明，本地加载扩展需要在 `chrome://extensions` 页面启用开发者模式，然后选择包含 `manifest.json` 的扩展目录。[1]

1. 下载或克隆本仓库：

   ```bash
   git clone https://github.com/EvanTop/smailr-mail-assistant.git
   ```

1. 在 Chrome 或其他 Chromium 浏览器中打开 `chrome://extensions` 。

1. 打开右上角的**开发者模式**。

1. 点击**加载已解压的扩展程序**，选择克隆或解压后、包含 `manifest.json` 的 `smailr-mail-assistant` 文件夹。

1. 建议在浏览器扩展菜单中将 **Smailr 邮件助手**固定到工具栏，以便随时打开。

> 每次修改 `manifest.json` 或后台服务代码后，请回到扩展管理页点击该扩展的刷新图标。Chrome 的官方说明对需要重新加载的组件有更详细的说明。[1]

## 首次配置

扩展使用 Smailr API 密钥完成读取，不会自动使用浏览器中已登录的 Smailr 网页账户。

1. 点击浏览器工具栏中的 **Smailr 邮件助手** 图标。

1. 点击底部的**打开开发者页面**，或访问 [Smailr 开发者页面](https://smailr.com/app/manage/developer)。

1. 在 Smailr 中创建 API 密钥。建议仅授予 `mailbox:read` 和 `mail:read` 权限。

1. 复制以 `nm_` 开头的密钥，粘贴到扩展的配置框中并保存。

1. 首次同步会建立未读基线；后续发现未读数量增加时才会进入新邮件提醒流程。

扩展会为第一个账户使用默认名称“账户 1”。你可以在**提醒设置 → 账户管理**中点击账户右侧的铅笔图标，将其改为更易识别的名称。

## 日常使用

| 操作 | 使用方式 | 结果 |
| --- | --- | --- |
| 刷新邮件 | 点击主界面右上角的刷新图标 | 立即请求当前账户的 Smailr 邮箱与收件箱数据。 |
| 切换邮箱 | 在主界面的邮箱下拉菜单中选择地址 | 切换当前账户内的邮箱，并查看该邮箱的邮件。 |
| 查看邮件 | 点击邮件行 | 读取邮件详情；若该邮件尚未在扩展中确认，相关提醒数会立即减一。 |
| 复制正文 | 进入详情页后点击“复制正文” | 将可显示的邮件正文复制到系统剪贴板。 |
| 隐藏邮件 | 点击邮件行右侧的删除图标 | 仅从扩展的本地列表隐藏该邮件，不影响 Smailr 原始邮件。 |
| 清除提醒 | 点击主界面未读数字角标 | 清除当前账户的本机待提示提醒，不会改变 Smailr 服务端的未读状态。 |
| 管理账户 | 打开设置中的“账户管理” | 可添加、切换、改名或从本机移除账户。 |

### 提醒与同步逻辑

当自动检查开启时，扩展会按设置的间隔检查**当前激活账户**。同一账户在刷新请求重叠时会合并为一次请求，以减少重复网络请求。关闭“后台检查新邮件”后，不会执行定时检查、启动检查或切换账户时的自动同步；此时只有点击主界面右上角刷新按钮才会读取邮件。

每个账户都拥有独立的提醒状态。因此，在账户 A 清除提醒或打开一封邮件，不会清除或影响账户 B 的工具栏角标、待提示未读数或已确认邮件记录。

### 打开网页邮箱的说明

底部的**打开浏览器网页邮箱**会打开 `https://smailr.com/app/` 。该网页使用的是浏览器当前的 Smailr 登录会话，**不会**使用扩展中保存的 API 密钥；如果网页端已登录的是另一个账户，打开后可能显示不同的网页邮箱账户。

## 数据与隐私

扩展请求仅指向 `https://smailr.com/*` ，并使用 API 密钥作为 Bearer Token 读取邮箱列表、收件箱邮件与单封邮件详情。扩展实际使用的邮件接口均为 `GET` 请求；不会通过该扩展删除、修改、标记已读或归档 Smailr 服务端邮件。

下列信息存放在当前浏览器扩展的本地存储中：API 密钥、账户名称、同步缓存、邮箱备注、提醒确认记录和本地隐藏邮件记录。扩展不会将这些信息转发至第三方服务；但浏览器本地存储不是独立的密码保险箱，因此请保护好浏览器用户配置文件，并在不再使用时从扩展中移除账户或在 Smailr 开发者页面撤销对应密钥。

| 清单权限 | 用途 |
| --- | --- |
| `storage` | 保存账户设置、缓存、备注和本地隐藏记录。 |
| `alarms` | 根据用户设置执行后台轮询。 |
| `notifications` | 显示新邮件系统通知。 |
| `offscreen` | 在后台播放本地生成的提示音。 |
| `https://smailr.com/*` | 访问 Smailr API 与打开 Smailr 网页地址 。 |

项目采用 Manifest V3；该扩展平台以按需运行的 Service Worker 作为后台上下文，并对扩展执行的远程代码进行限制。[2]

## 已知边界

- 扩展当前仅读取每个邮箱收件箱的前 15 封邮件，不提供发信、回复、移动、归档或服务端删除功能。

- “本地隐藏”与“清除提醒”仅影响扩展的本地显示与提醒状态；它们不会改变原邮箱的邮件或未读状态。

- 最多可管理 8 个账户。

- 关闭自动检查后，需要手动点击刷新按钮更新邮件。

- 系统通知与声音是否实际展示，还取决于浏览器、操作系统的通知权限与静音状态。

- 本项目不是 Smailr 官方产品，也不隶属于 Smailr。

## 项目结构

```
smailr-mail-assistant/
├── manifest.json       # 扩展清单与权限声明
├── background.js       # Service Worker：同步、缓存、提醒与账户隔离
├── popup.html          # 工具栏弹窗骨架
├── popup.js            # 弹窗交互与渲染
├── popup.css           # 弹窗样式
├── offscreen.html      # 离屏提示音页面
├── offscreen.js        # 本地 Web Audio 提示音逻辑
└── icons/              # 扩展图标资源
```

## 本地开发

本项目不依赖构建步骤或第三方运行时依赖。修改后，在 `chrome://extensions` 中刷新扩展即可验证：`popup.js`、`popup.css` 和 `popup.html` 的改动重新打开弹窗即可查看；`manifest.json` 与后台服务改动需要在扩展管理页刷新。[1]

请勿将真实 API 密钥提交到 Git 仓库、截图、Issue 或日志中。
